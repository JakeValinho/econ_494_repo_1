## Assignment

Reproduce a main result from an AER paper in a programming language different from the authors' original implementation, inspect the original code for coding or reproducibility issues, and evaluate their effects.

The authors use **Stata**. This repository reproduces **Table 5** in **R**.

## Target: Table 5 — Total expenditure and saving regressions

The original table is generated by `hh-survey-results.do` using `urban_lprob.dta` and the saved bootstrap draws in `boot_results.dta`.

The authors:

1. run four OLS regressions with the same age/race/state control structure;
2. use predicted veteran probability interacted with the relevant post-bonus indicator;
3. obtain the displayed standard errors from 1,000 bootstrap replications;
4. bootstrap entire **city clusters within strata** and re-estimate veteran probability in every draw.

## Independently rerun the bootstrap

`R/03_full_bootstrap.R` implements the authors' city-within-strata bootstrap in R. The default is 1,000 replications.

Because R and Stata use different random-number implementations, the exact bootstrap draws will differ even with the same seed. The useful comparison is whether the resulting standard errors are close.

## Audit findings

See `audit/audit_log.md` and `audit/verification_results.md` for details.

1. **Column (4) labeling error.** The dependent variable is `bonus_spent`, defined in the original code as the amount of the soldiers' bonus spent for current living, but it is mislabeled “Cash gifts received.” This affects interpretation, not estimates.
2. **Main bootstrap block commented out.** `run_bootstrap.do` does not regenerate the main Table 5 bootstrap draws unless the user manually re-enables the commented block. The supplied `boot_results.dta` still reproduces the published SEs.
3. **$5,000 wording discrepancy has zero numerical effect.** The code uses `tot_expen < 5000`, while the table wording says to omit spending above $5,000. There are zero observations exactly equal to $5,000, so the distinction does not change the sample.
4. **Hard-coded local paths.** The original Stata code contains an author-specific Dropbox path.
5. **Bootstrap SEs matter.** A naive R translation using default `lm()` standard errors changes inference. For example, column (1)'s interaction has an OLS p-value around 0.021 but approximately 0.088 using the published bootstrap SE.
